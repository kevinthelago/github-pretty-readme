How it works

Three steps. Then it runs every morning at 5 UTC.

Once you connect, a GitHub Action lands in your profile repo and refreshes everything daily.

01 / CONNECT

Sign in with GitHub.

One click — no token creation, no copy-pasting. Revokable from GitHub settings at any time.

02 / GENERATE

Preview & apply.

AI reads every repo, scores quality across six dimensions, and drafts READMEs, topics, and a SCORE.md for each.

03 / FORGET

The Action takes over.

Add a GH_PAT secret to your profile repo and everything updates overnight — profile, descriptions, the lot.
