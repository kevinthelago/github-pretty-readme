# Security Policy

## Supported Versions

| Version | Supported |
| :------ | :-------- |
| latest  | ✅        |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report vulnerabilities privately by emailing **kevinthelago@gmail.com** with:

- A description of the vulnerability and its potential impact
- Steps to reproduce or a proof-of-concept
- Any suggested fixes (optional)

You can expect an acknowledgement within 48 hours and a resolution or status update within 7 days.

## Scope

This policy covers the hosted service at any deployed instance of `github-pretty-readme` and the source code in this repository. Self-hosted deployments are the responsibility of the operator.
